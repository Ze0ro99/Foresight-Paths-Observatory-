# Docker Deployment

This repository is a Next.js application configured for standalone output. The image runs the standalone server as a non-root user.

## Configure

1. Copy `.env.example` to `.env` and fill required values. Compose requires this file.
2. Use `PI_NETWORK=Pi Testnet`, `PI_SANDBOX_MODE=false`, `PI_DIRECT_TESTNET_ENABLED=true`, and `NEXT_PUBLIC_PI_SANDBOX_MODE=false` for the registered Testnet app. This enables direct Testnet SDK identity only; it does not enable payment execution.
3. Keep `NEXT_PUBLIC_PI_PAYMENTS_ENABLED=false` so identity login requests only the `username` scope. Leave server payment, ledger, entitlement, and Mainnet flags false.
4. Set `GEMINI_MODEL=gemini-3.8-flash` unless you have deliberately selected another model supported by your Google AI Studio key. Set `GEMINI_API_KEY` only in the server-side `.env` file. For Supabase, `SUPABASE_SERVICE_ROLE_KEY` may contain a modern `sb_secret_...` key or a legacy service-role JWT; never use a publishable key for private RPCs.
5. Supply `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` at build time when the browser bundle requires them. They are public values.
6. Never put `SUPABASE_SERVICE_ROLE_KEY`, `PI_API_KEY`, `GEMINI_API_KEY`, or other private credentials in build args, image labels, source control, or any `NEXT_PUBLIC_*` variable.

## Build and run

```sh
docker compose build
docker compose up -d
docker compose ps
docker compose logs -f foresight-paths
```

Open http://localhost:3000. The port is bound to loopback only; use a TLS reverse proxy before exposing it externally.

## Smoke check

```sh
curl -fsS http://localhost:3000/api/health
```

Compose uses `/api/health` as its healthcheck. Verify the route exists and returns 2xx in this revision before relying on container health. This setup does not enable Pi payments, Mainnet, signing, or agent execution.

## Notes

- This branch has no committed `package-lock.json`. Docker copies only `package.json` and uses `npm install --package-lock=false`, so a transient lockfile generated by CI cannot break the image build. Add and validate a committed lockfile in a separate dependency-maintenance change before switching to `npm ci`.
- Next.js public environment values are build-time values. Rebuild the image when they change.
- The image tag is local (`foresight-paths:local`). Publish only after CI and the Docker build pass.
- The healthcheck only confirms that `/api/health` responds successfully; inspect the JSON body for incomplete integrations before treating the app as fully ready.
